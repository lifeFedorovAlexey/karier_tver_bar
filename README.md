# Карьер — кафе и баня у воды

Сайт на Next.js App Router. Публичные страницы: главная, кафе, баня, прокат, меню и контакты. Страницы отдаются как готовый HTML и не требуют JavaScript для основного контента и навигации.

## Запуск

Требуется Node.js 22.12+. CI использует актуальный Node.js 22.

```bash
npm install
npm run dev
```

Полная проверка:

```bash
npm run check
```

Инструкция по выкладке на стенд: [`DEPLOY.md`](./DEPLOY.md).

## Настройка перед публикацией

1. Скопировать `.env.example` в `.env.local`.
2. Указать боевой URL в `NEXT_PUBLIC_SITE_URL`.
3. После создания счётчика добавить `NEXT_PUBLIC_YANDEX_METRIKA_ID`. Без ID Метрика не загружается.
4. Подтвердить телефон, почту, режим работы, геоточку и позиции меню в `lib/site.ts` и страницах.
5. После изменения публичных переменных выполнить новую сборку и деплой.

## Поисковая индексация

Основной адрес: `https://tverplazh.ru`. Приложение постоянно перенаправляет
`www.tverplazh.ru` и `147.45.189.80` на основной адрес, сохраняя путь и параметры.
HTTP → HTTPS и сертификаты обслуживает nginx на сервере. Второй домен `.online`
нужно подключать отдельно на уровне DNS, сертификата и nginx.

Проверка `npm run check` после сборки проверяет готовые HTML-страницы, canonical,
уникальные title/description, микроразметку, sitemap, robots и перенаправления.

В Яндекс Вебмастер добавляется именно `https://tverplazh.ru`. Файл подтверждения
`public/yandex_30d979d06d403ed8.html` нужно сохранять при следующих деплоях.
После подтверждения прав отправить `https://tverplazh.ru/sitemap.xml` в разделе
«Индексирование → Файлы Sitemap», отправить шесть публичных страниц на переобход
и указать регион «Тверь» со ссылкой на `/contacts`.

Метрика подключается только после задания `NEXT_PUBLIC_YANDEX_METRIKA_ID`
в GitHub Actions Variables и новой сборки. Уже предусмотрены цели
`booking_click`, `phone_click`, `menu_open`, `map_open`.
