# Карьер — кафе и баня у воды

SSR-ready сайт на Next.js App Router. Публичные страницы: главная, кафе, баня и контакты. Страницы отдаются как готовый HTML и не требуют JavaScript для основного контента и навигации.

## Запуск

Требуется Node.js 22.12+.

```bash
npm install
npm run dev
```

Полная проверка:

```bash
npm run check
```

Инструкция по выкладке на стенд: [`DEPLOY.md`](./DEPLOY.md).

## Настройка перед публикацией

1. Скопировать `.env.example` в `.env.local`.
2. Указать боевой URL в `NEXT_PUBLIC_SITE_URL`.
3. После создания счётчика добавить `NEXT_PUBLIC_YANDEX_METRIKA_ID`. Без ID Метрика не загружается.
4. Подтвердить телефон, почту, режим работы, геоточку и позиции меню в `lib/site.ts` и страницах.
5. Подключить обработчик формы вместо временного `mailto:`.
